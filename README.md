## 🎯 Mission

Develop and deploy an electric vehicle (EV) charging station network in Brazil with a DIY approach that reduces costs by **86% compared to commercial solutions**.

---

## 💡 The Problem

**Current EV charging infrastructure in Brazil is broken:**

- 💰 Commercial stations cost R$ 25,000 - R$ 50,000 (prohibitive)
- 📉 Only 3,200 public charging points for 100,000+ EVs
- 🗺️ 70% concentrated in São Paulo and Rio de Janeiro
- 🌍 90% of stations are imported (inflated prices)
- 🔒 Proprietary technology (vendor lock-in)

**To meet 2027 demand:** 15,000 stations needed = **R$ 525 million investment** (traditional market)

---

## 🚀 Our Solution

### Bifrost Charging Station

**Open-source DIY approach:**

✅ **Cost:** R$ 4,987 per station (86% cheaper)
✅ **Open Hardware:** KiCad design, replicable
✅ **Open Software:** Symfony backend, React frontend
✅ **INMETRO Certified:** IEC 61851-1 compliant
✅ **Complete Platform:** Backend + Mobile App + Dashboard

### Technical Specifications

| Feature | Specification |
|---------|--------------|
| **Power** | 7.4 kW (32A single-phase) |
| **Connector** | Type 2 (Mennekes) |
| **Protocol** | OCPP 1.6J / 2.0.1 |
| **Connectivity** | 4G LTE + WiFi + Ethernet |
| **Display** | 7" TFT touchscreen LCD |
| **Payment** | RFID + QR Code + App + Credit card |
| **Safety** | RCD, overcurrent, overvoltage protection |
| **Certification** | INMETRO IEC 61851-1 ✅ |
