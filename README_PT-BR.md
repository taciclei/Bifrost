---

## 📋 Visão Geral do Projeto

### Missão
Desenvolver e implantar uma rede de estações de recarga para veículos elétricos (Eletroposto) no Brasil, com abordagem DIY para reduzir custos em 86% vs soluções comerciais.

### Visão
Tornar-se líder em soluções de recarga VE acessíveis no Brasil até 2027, com 100+ estações implantadas.

### Objetivos Estratégicos
- ✅ **Curto prazo (6 meses):** Protótipos validados e testados
- 🔄 **Médio prazo (12 meses):** Certificação INMETRO + 5 estações piloto
- 🎯 **Longo prazo (24 meses):** 100 estações operacionais

## 🛠️ Stack Tecnológico

### Hardware
- **KiCad 9.0+** - Design PCB
- **IEC 61851-1** - Norma internacional
- **ABNT NBR IEC 61851-1** - Norma brasileira
- **STM32F407VGT6** - Microcontrolador
- **OCPP 1.6/2.0.1** - Protocolo comunicação

### Software Backend
- **Symfony 6.4** - Framework PHP
- **API Platform 3.2** - API REST
- **PostgreSQL 16** - Banco de dados
- **Redis** - Cache
- **Mercure** - Real-time

### Software Frontend
- **React 18** - Interface web
- **TypeScript** - Tipagem
- **Tailwind CSS** - Estilização
- **React Query** - Gerenciamento estado

### Mobile
- **React Native 0.73** - App móvel
- **Expo** - Toolchain

### Infraestrutura
- **Docker** - Containerização
- **Kubernetes** - Orquestração
- **AWS/Azure** - Cloud
- **Terraform** - IaC
- **GitHub Actions** - CI/CD
